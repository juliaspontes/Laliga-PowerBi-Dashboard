# 📊 LaLiga Historical Analysis Dashboard

Dashboard interativo desenvolvido no Power BI com o objetivo de analisar o histórico da LaLiga, explorando métricas ofensivas e aplicando storytelling com dados para geração de insights estratégicos.

## 🚀 Objetivo

Transformar dados históricos da LaLiga em visualizações claras e intuitivas, permitindo identificar padrões ofensivos, comparar desempenhos ao longo das temporadas e apoiar análises baseadas em dados.

## 🧠 Principais Análises
✔️ Temporada mais ofensiva  
✔️ Média de gols por jogo  
✔️ Comparação de gols como mandante vs visitante  
✔️ Evolução de gols por rodada  
✔️ Identificação da maior goleada do período  

## 📈 Insights que podem ser extraídos
- Algumas temporadas concentram maior volume ofensivo
- Jogos como mandante tendem a apresentar maior número de gols
- Rodadas específicas concentram picos ofensivos relevantes
- A análise histórica permite identificar padrões recorrentes de ataque

## 🛠️ Ferramentas Utilizadas
- Power BI
- DAX (criação de métricas e KPIs)
- Modelagem de dados
- Data Visualization
